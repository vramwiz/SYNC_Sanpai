# 参拝演出（SYNC_Sanpai）

AviUtl2 2.1.16 以降の Win64 用メディアオブジェクトです。絵と効果音はプラグイン内で生成します。

「メディアオブジェクトの追加」から「SYNC」の「参拝演出」を配置します。1オブジェクトにつき1シーンを指定し、切り替えや立ち絵はタイムライン上で組み合わせます。ドロップダウンは賽銭箱（正面）、賽銭箱（背面）、鈴（正面）、鈴（背面）、おみくじをひく、おみくじの結果の順です。

## シーン

| シーン | 演出 |
| --- | --- |
| 賽銭箱（正面・背面） | 硬貨0～30枚と紙幣0～10枚を投げ入れます。両方を0枚にすると静止します。初期値は硬貨1枚、紙幣0枚です。投入位置はX・Yで調整できます。 |
| 鈴（正面・背面） | 揺れに合わせて鈴緒がしなります。強さは0～100、初期値は50です。 |
| おみくじをひく | 取り出し口を下に向けて筒を振り、下側から棒が1本出ます。筒を振る強さの初期値は50です。 |
| おみくじの結果 | 選んだ運勢を和紙1枚に表示します。表示方法はそのまま、折り開き、巻き広げ、裏返し、下からの引き出しの5種類です。紙と文字の色を設定でき、枠は文字色に連動します。 |

正面には神社の背景があります。背面は透明で、鈴の背面には吊り金具を支える天井の一部が付きます。

賽銭箱と鈴は、それぞれもう一方を補助オブジェクトとして表示できます。相対座標の初期値（0, 0）は鈴が上、賽銭箱が下に来る配置です。座標は1280×720を基準とする描画上のピクセル単位です。

「賽銭投入X座標」「賽銭投入Y座標」は格子中央からの相対位置です。Xは右、Yは下が正方向で、初期値はどちらも0です。複数枚は指定位置の周辺へ落ちます。

## おみくじの位置と結果演出

「おみくじをひく」「おみくじの結果」には「おみくじ共通」が表示されます。「おみくじX」「おみくじY」で中心からの相対位置を、「おみくじ拡大率」で対象の大きさを調整できます。初期値はX＝0、Y＝0、拡大率100%です。座標は右と下が正方向で、各オブジェクトで個別に設定できます。

「おみくじの結果」の「結果演出」は「ふわっと登場」が初期値です。「フェードイン」「軽く弾む」「なし」も選べます。「表示方法」と組み合わせて使えます。紙を開く・広げる等とフェードインを組み合わせると、文字と枠が徐々に現れます。

## 色設定

全シーン共通の「色設定」に、木、土台、賽銭箱、鈴、鈴緒、おみくじ筒、文字、紙の8色があります。木の色は拝殿と鈴の吊り梁に、土台の色は段差や床に適用されます。

## 時間と効果音

- 「演出開始までの時間」「演出の時間」は秒単位で、0.01秒刻みです。初期値はいずれも1.00秒です。
- 「演出の時間」を0秒にすると、開始時刻で完了状態に切り替わります。
- 硬貨、鈴、おみくじ筒の効果音は「効果音」と「音量」で設定できます。初期値はON・50で、音量100が生成音の元の音量です。

旧版で「おみくじ筒」または「おみくじ」を選んだ箇所は、「おみくじをひく」または「おみくじの結果」を選び直してください。ビルドや検査の手順は [作業ノート](note.md) を参照してください。
